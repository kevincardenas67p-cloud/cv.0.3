¿Qué es HTML?

HTML es un lenguaje de marcado utilizado para crear la estructura de las páginas web.

Permite organizar títulos, párrafos, imágenes, enlaces, listas, formularios y otros elementos.

¿Qué es GitHub?

GitHub es una plataforma utilizada para almacenar y administrar proyectos de programación.

También permite trabajar con Git y llevar un control de los cambios realizados en un proyecto.

¿Qué es la programación?

La programación consiste en crear instrucciones que permiten a un computador realizar diferentes tareas.

Aprender programación ayuda a desarrollar la lógica y la capacidad para solucionar problemas.

¿Qué es el desarrollo web?

El desarrollo web consiste en crear sitios y aplicaciones que funcionan mediante internet.

Algunas tecnologías utilizadas en el desarrollo web son HTML, CSS y JavaScript.
